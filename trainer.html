1. Что нужно написать

В поле каждой задачи напишите функцию с именем solve. Она принимает один аргумент — строку (в примерах она называется s) — и с помощью return возвращает результат. Это единственная форма ответа: тренажёр сам подставит в вашу функцию проверочные строки и сравнит результат с правильным.

function solve(s) { // ваши действия со строкой s return результат; // обязательно вернуть! }

2. Разобранный пример — так выглядит готовое решение

Задача: «вернуть строку без крайних пробелов, в нижнем регистре». Решение:

function solve(s) { return s.trim().toLowerCase(); } // solve(" ПРИВЕТ ") вернёт "привет"

Никаких console.log, prompt и чтения ввода не нужно — только функция и return. Тренажёр сам выведет результат в отчёт по тестам.

3. Как проходит проверка

Нажмите «Проверить» — под задачей появится отчёт по каждому тесту: вход, «ожидалось» и «получено». Зелёная строка ✓ — тест пройден, красная ✗ — ваша функция вернула не то (сравните строки «ожидалось» и «получено»). Задача решена, когда пройдены все тесты. Если в коде ошибка — тренажёр покажет её текст: исправьте и проверьте снова.

4. Практические правила

  • В каждой задаче — своя функция solve, писать надо только её, один раз.
  • Кнопка «Шаблон» вставляет заготовку функции — дальше дописываете тело.
  • Кнопка «Подсказка» подскажет нужные методы, но не даст готовый код.
  • Код каждой задачи сохраняется в браузере автоматически — можно закрыть страницу и вернуться позже.
  • Используйте только методы из лекции: trim, slice, replace, replaceAll, split, join, indexOf, includes, toUpperCase, toLowerCase, length.
  • Пишите код маленькими шагами: добавили метод — сразу «Проверить», так легче найти ошибку.

Код сохраняется в вашем браузере (localStorage). Тренажёр выполняет ваш код локально — открывайте только собственные решения.
