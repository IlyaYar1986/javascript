Ключевой слайд лекции. Не спешить: сначала «s[0] = X» и «s.trim() без сохранения», потом «s = s.trim()».

let str = "  Привет  ";
let fixed = str.trim();     // новая строка — результат нужно сохранить
console.log(str);    // "  Привет  " — исходная НЕ изменилась
console.log(fixed);  // "Привет"

str.trim().toUpperCase();   // ✗ результат потерян
let clean = str.trim().toUpperCase();  // ✓ "ПРИВЕТ"
  • Вызов метода — выражение с результатом: присвойте, верните, передайте дальше.
  • Именно поэтому работают цепочки методов: каждый шаг отдаёт новую строку.

Связать с демонстрацией на предыдущем слайде — там это видно руками.

Кликните по символу. Обратить внимание: за границей — undefined, ошибки нет; length — свойство, без скобок.

Дать ввести подстроку "a" и "example"; обратить внимание на подсветку вхождений.

indexOf возвращает индекс, а не «да/нет». А в условии «ложными» считаются и −1, и 0 — а 0 значит «нашли в самом начале!»

Провести мини-квиз голосованием, потом обсудить правильное условие: !== -1 или startsWith.

Извлечение: slice

  • Конец диапазона не включается: "JavaScript".slice(0, 4) → "Java"
  • Отрицательные индексы — отсчёт с конца: slice(-6) → "Script"
  • substring отрицательные превращает в 0; substr устарел

Замена и преобразования

  • trim() — убрать пробелы по краям
  • toUpperCase() / toLowerCase() — регистр

Ловушка «replace меняет только первое вхождение» — вторая по частоте после потерянного результата.

Строка ↔ массив: split и join

"яблоко,банан,груша".split(",")
  // → ["яблоко", "банан", "груша"]

["2026", "11", "11"].join("-")   // → "2026-11-11"
  • split превращает строку в массив, join — обратно.
  • Вместе с методами массивов — мощный конвейер. Смотрите следующий слайд.

Проговорить: это мост к теме «массивы»; пара split/join используется постоянно.

Самый практичный приём лекции. Пройти по шагам: trim → split → map → join.

  • Равенство — ===. Порядок (<, >) — по кодам Unicode: заглавные «меньше» строчных!
  • Сортировка по-русски — a.localeCompare(b); ввод перед сравнением — s.trim().toLowerCase()

Разгадка «Почему Я < я» — в показе кодов символов. Спросить: когда toLowerCase недопустим? (пароль)

Три инструмента из уже изученных методов

// 1. Инициалы из ФИО
"иванов иван иванович".trim().split(/\s+/)
  .map(n => n[0].toUpperCase()).join(".") + "."   // "И.И.И."

// 2. Маскировка номера
digits = phone.replace(/\D/g, "");
digits.slice(-4).padStart(digits.length, "*")   // "*******4567"

// 3. Проверка e-mail (упрощённая)
at = e.indexOf("@");
if (at <= 0 || at === e.length - 1) return false;
  • Ничего нового — только комбинация изученных методов.

Показать, что весь «взрослый» код — конструктор из простых блоков. Эти же задачи будут в тренажёре.

  1. str.trim() — результат не сохранён

  1. new String("...") — объект, ломает ===
  2. путаница slice/substring при отрицательных
  3. сравнение ввода без trim().toLowerCase()
